SmoothWatch (Fabric, Minecraft 26.2, Java 25)

Сборка:   gradle wrapper && ./gradlew build     (jar в build/libs/)
Установка: положить jar в .minecraft/mods/ вместе с Fabric API.
Логи:     .minecraft/logs/latest.log, искать "SmoothWatch".

Рекомендуемые JVM-аргументы (лаунчер -> настройки Java):
  -Xms4G -Xmx4G -XX:+UseZGC -XX:+DisableExplicitGC -XX:+AlwaysPreTouch
